# Sherlock GO

Sherlock GO is a rewrite of sherlock in Golang.
The project is currently feature complete and will be updated if sherlock gets updated to bring in the latest features from the parent project it's based on.

The goal is to simply just have a working version of sherlock that has the same functionality but does not require python or heavy python dependencies in order to work.
